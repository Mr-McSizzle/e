# ERCHOMAI / THE ARRIVAL

A standalone, responsive coming-soon experience for Erchomai — applied AI R&D and bespoke implementation services, pursuing the Company Brain philosophy.

## Deploy on Netlify

1. Choose **Add new project → Import an existing project → GitHub**.
2. Select `Mr-McSizzle/e` and branch `main`.
3. **Base directory:** leave blank. **Build command:** leave blank. **Publish directory:** `.` (the repository root).
4. Deploy, then connect your own domain in Netlify's domain settings. Enable HTTPS and verify the production hostname and redirects.

No npm, build framework, APIs, database, secrets, or environment variables are needed. Do not enable Netlify analytics, identity, forms, or third-party tracking without revisiting privacy and consent requirements. This repository is public; no secret keys belong in it.
